# Architecture DeXe

Les contrats sont organisés autour de registres et de modules réutilisables. Les scripts de déploiement relient les implémentations aux adresses et aux paramètres d’un environnement donné.

Cette modularité permet de composer une DAO adaptée tout en isolant les responsabilités de gouvernance et de trésorerie.
