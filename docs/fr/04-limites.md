# Limites et périmètre

Le protocole vise la flexibilité, mais celle-ci augmente la surface de configuration : registres, experts de prix, pools et droits d’administration doivent être cohérents. Les audits présents dans le dépôt sont des références, pas une garantie actuelle.

Aucun test, build ou déploiement n’a été exécuté pour ce parcours.
